# Проект
Данная директория предназначена для написания дипломной работы. На тему проекта, который написан и исходный код которого можно увидеть в `../core_service`, `../accessories_processing`, `../frontend`, `../`

## Инструкции
1. Посмотри примеры
2. Процесс написания будет инкрементальный:
3. Примерно придумать оглавление - какие главы будут
4. Пишем по одной главе, обсуждаем и задаем вопросы. Писать главу в документ будем, только когда я скажу записать главу, до тех пор обсуждаем и смотрим демонстрационную версию главы.
5. Записываем главу в md
6. Дал согласие - переходим к следующей главе

### Стиль
Посмотри на примеры `reference.docx` и `template.md`

В результате получил markdown файл с дипломом, который соответствует стилям из примера

## Инструменты

По просьбе перевести в docx исполнить комманду `pandoc report-nir.md -o report-nir.docx --reference-doc=reference.docx`

### Делай ресерч при желани вставить метрики

генерируй диаграмы с помощью claude mermaid
